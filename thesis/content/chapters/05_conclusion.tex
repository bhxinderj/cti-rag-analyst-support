\chapter{Conclusion, limitations, and outlook}
\label{ch:conclusion}

\section{Summary and contributions}
\label{sec:summary}

This thesis designed, implemented, and evaluated a RAG prototype for
CTI analyst support. The prototype combines a provenance-preserving
index of four curated CTI sources (84{,}982 documents), hybrid
retrieval with reranking, and a layered generation pipeline in which
deterministic facts are rendered from passage metadata, the LLM
narrates only within the retrieved context, and citations are enforced
and validated; the stack is open-source and was operated on consumer
hardware throughout. The evaluation compared six configurations
(V0--V5) on a frozen index state, with 28 queries across four task
types and three runs per configuration, complementing RAGAS metrics
with field coverage, an analyst rubric, and scenario walk-throughs.
The central finding is that answer correctness stays at the level of
the non-retrieval baseline while traceability rises from 1.23 to 2.56:
on this query set, retrieval buys verifiability rather than raw
correctness.

The scientific contribution is workflow-level empirical evidence for
RAG in CTI (four task types under one architecture, with an ablation
that separates retrieval strategy and generation mode), the finding
that generic RAG metrics and analyst-oriented measures diverge, and a
reference model of eight design principles, each stated with its
empirical basis (G1--G3, SRQ3). The practical contribution is a
reproducible, locally deployable system whose repository regenerates
every reported number, table, and figure, together with a quantified
local-versus-hosted trade-off that turns the deployment question into
a measured comparison.

\section{Limitations}
\label{sec:limitations}

The validity of the results is bounded by the following limitations:

\begin{itemize}
    \item \textbf{Corpus and query set scope:} The evaluation ran on
          one frozen corpus of four curated, English-language sources
          and a query set of 28 queries. This scope supports controlled
          comparison; transfer to other corpora, languages, and
          organizations requires validation.
    \item \textbf{Query-set bias toward the baseline:} The query set
          names prominent, well-documented CVEs, which the parametric
          baseline answers from training data. The correctness
          comparison therefore reads as a conservative estimate of the
          retrieval benefit (Section~\ref{sec:results-ablation}).
    \item \textbf{LLM-as-judge scoring:} All RAGAS scores come from a
          single judge model and inherit its biases
          \parencite{akkiraju2024facts}. The relevancy filter
          illustrates the risk: it nulled non-committal answers of the
          local and the hosted generator alike
          (Section~\ref{sec:results-generation}), a property of the
          judge metric rather than of one model.
    \item \textbf{Context metrics are proxies:} Context precision and
          context recall are reference-based, LLM-judged proxies, not
          classical IR metrics; document-level relevance judgments
          (qrels) do not exist for this corpus. Per-stage retrieval
          traces are preserved in the evaluation artifacts, so a
          qrels-based ranking evaluation remains feasible future work
          (Section~\ref{sec:future-work}).
    \item \textbf{Self-evaluation without a user study:} The
          scenario-based assessment was performed by the author along
          the rubric fixed before the results
          (Appendix~\ref{app:query-set}); no study with practicing
          analysts was conducted. Statements about operational
          usefulness rest on structured self-assessment.
    \item \textbf{No runtime source assessment:} Ingestion is limited
          to curated sources with preserved provenance, but the
          prototype does not score source credibility at query time;
          C3 is fulfilled only partially
          (Section~\ref{sec:assessment}).
    \item \textbf{Residual narrative inconsistencies:} The layered
          design limits the impact of narrative errors --- the
          deterministic facts remain correct --- but does not eliminate
          them; Section~\ref{sec:scenario-cross} shows a gaps statement
          contradicting the Layer-1 table of the same answer.
\end{itemize}

\subsection*{Scientific follow-up}

\begin{itemize}
    \item \textbf{Qrels-based retrieval evaluation:} The evaluation
          artifacts preserve per-stage retrieval traces (BM25, vector,
          fused, and reranked rankings) for every run. Adding
          document-level relevance judgments to the existing queries
          would enable classical IR metrics and separate ranking
          quality from generation effects, complementing the
          LLM-judged context proxies of this thesis.
    \item \textbf{User study with practicing analysts:} A study with
          analysts would replace the structured self-assessment,
          validate the rubric dimensions, and test whether the triage
          structure holds in real investigations.
    \item \textbf{Corpus and organization transfer:} Larger and
          multilingual corpora and other organizational contexts would
          test whether the reference model of
          Section~\ref{sec:reference-model} generalizes beyond the
          evaluated snapshot.
    \item \textbf{Model comparison under governance constraints:} The
          local-versus-hosted ablation provides the template for a
          systematic comparison of generation models under explicit
          data-governance constraints, including the exploratory
          extended assist mode, which is documented but not evaluated
          in this thesis.
\end{itemize}
